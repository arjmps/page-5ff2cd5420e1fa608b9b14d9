Platforms

终端与核心适配

HQExpress 依赖标准化网络协议，支持各主流平台的主流分流内核。

桌面操作系统 (Windows / macOS / Linux)

桌面环境推荐使用支持 Clash 规则或 Sing-box 核心的管理程序。通过导入订阅链接，程序可自动根据目标域名和 IP 集合判定直连或代理路径。

核心建议: Clash Verge / Clash.Meta
配置类型: Remote Subscription URL
分流模式: Rule-based

iOS / iPadOS 设备

移动端可选用兼容标准订阅解析的应用。将订阅地址粘贴至配置栏后，拉取节点集群并启用本地 VPN 隧道即可生效。

应用参考: Shadowrocket / Loon / Quantumult X
环境要求: iOS 14.0 或更高版本
更新机制: 后台定时静默同步

Android 终端

Android 平台具备开源分流工具生态。用户可自选遵循通用规范的客户端，手动开启分应用代理或 TUN 虚拟网卡接管系统数据流。

核心建议: Clash for Android / v2rayNG / Sing-box
架构支持: arm64-v8a / armeabi-v7a
运行模式: TUN Mode
Deployment

初始化接入流程

从获取凭据到建立数据通路的标准化四步。

STEP 01

选定订阅方案

根据团队或个人使用的设备数量与月度传输额度，确认所需的服务级别，并在系统后台生成对应的订阅凭证。

STEP 02

获取订阅链接

在用户控制面板复制专属的订阅 URL。注意该链接包含访问密钥，请勿公开传播或写入不信任的公开脚本。

STEP 03

载入客户端

在对应系统的分流软件中创建订阅配置，粘贴链接并执行首次拉取，节点列表与策略组将自动加载至本地。

STEP 04

启动分流引擎

设置路由工作模式为“规则分流”，选择所需的主力或备用节点，启动网络接管并进行连通性检测。

Technical FAQ

常见问题排查与规范

关于链路使用、配额重置与协议调配的常见技术答疑。

节点列表无法正常更新应如何处理？

首先确认本地网络能够解析分发域名的 DNS 记录。如遇 ISP 劫持，可将客户端 DNS 修改为主流公共 DNS（如 1.1.1.1 或 8.8.8.8）。若依然受阻，请在控制面板尝试切换订阅转换源或重新生成访问密钥。

如何监控当前的流量消耗与在线设备？

登录 HQExpress 控制台主页即可查看本账期的已用流量与剩余额度。系统在握手阶段记录并发 IP 连接数，当在线设备数超出套餐上限时，较早建立的闲置会话将被自动切断。

国内与局域网流量是否计入套餐流量扣除？

在正确启用“规则模式（Rule）”的前提下，命中国内直连规则、私有局域网地址段（如 192.168.x.x / 10.x.x.x）的数据包不经由远端节点转发，因此不会计入订阅的流量统计。

月度重置周期的具体计算方式是什么？

流量重置并非统一在自然月首日，而是以初次订购生效日的零点为基准周期循环重置。如在某月 15 日订购，流量配额将在次月 15 日自动恢复为初始配额状态，未用额度不顺延。
